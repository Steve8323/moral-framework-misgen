Correction (an earlier version was an artifact). The first LLM task used "Grader's pick: A/B" — a verbatim copy of the answer label. A diagnostic showed the model just copied that token (content-acc 0.53 = chance with the cue removed): the dramatic 0/1 result was a token-copy artifact, not real sycophancy. This page uses a redesigned, realistic spurious correlation.
Credible result. For a realistically-imperfect spurious cue (≤95%) every seed reads content and aligns (alignment 1.0, content-acc 1.0). At p≈0.97 a genuine seed-driven spread appears (alignment ranges ~0.48–1.00) while content-accuracy stays 1.00 for every seed — the model demonstrably knows the right answer, yet the seed decides whether it deploys that knowledge or leans on the spurious source. Only as the source nears perfect (0.99–1.0) does it become spurious-dominant, and there the content representation starts to degrade (content-acc 0.78–0.85), so that regime is treated cautiously. No clean 0/1 bimodality — as expected for a real model, which is what makes it believable.
