Loss-equivalent models, different moral worldviews: a proof-of-concept

Generated 20260615_215623 · all numbers from real training runs on this machine (PyTorch, CPU; 1-hidden-layer MLP, width 64). No values are hand-set; figures plot raw outputs.

Core question (yours): are the loss-equivalent minima that LLMs reach far enough apart to be genuinely different "theories of thought" — one aligned, one not?

What this toy shows: (1) Two models can be loss-equivalent in-distribution yet hold opposite ethical frameworks (pure consequentialist vs pure deontologist), diverging only on conflict dilemmas. (2) Those two worldviews are NOT separated by a loss barrier — they are linearly mode-connected (zero barrier after permutation alignment), and the mechanism flips along a flat-loss path. (3) The default inductive bias, given redundant cues, is to hedge into a hybrid framework rather than commit.

Upshot: the loss landscape is blind to the moral-framework difference. "Different theories of thought" live in the same basin; only off-distribution behavioral probes reveal which worldview a model holds.
Novelty check (literature, June 2026). Two adjacent literatures exist: flat minima → better OOD/domain generalization (SWAD; "Seeking Consistent Flat Minima for Domain Generalization," CVPR 2025; ASGDRO) and SAM → reduced spurious/shortcut reliance ("SAM Enhances Feature Quality via Balanced Learning," 2024). Goal-misgen severity is also known to vary by seed (Langosco 2022; Colour-vs-Shape case study 2023). But no work measures goal-misgeneralization severity as a function of the KIND of minimum (the alignment-relevant, capability-retained construct) across the natural distribution of minima. Part 3 below does exactly that — this specific map appears unclaimed.

Setup

Each scenario carries a consequence cue (what a consequentialist weighs: the outcome, latent c) and a duty cue (what a deontologist weighs: rule/duty, latent d), each encoded by 4 noisy features, plus 8 pure-noise features. Action label = "act". Consequentialist policy: act iff c=1. Deontological policy: act iff d=1.

  • Agreement distribution (c=d): both frameworks prescribe the same action → any model that uses either cue is correct → loss-equivalent. This is where we measure the barrier.
  • Conflict distribution (c≠d, trolley/footbridge structure): the frameworks disagree → a model's choices reveal which framework it adopted. Metric = consequentialism index (1 = pure consequentialist, 0 = pure deontologist, 0.5 = hedged).

Part 3 — Does the KIND of minimum predict the LEVEL of goal misgeneralization?

Supervised analogue of goal misgeneralization: a hard-but-reliable true cue and an easy spurious cue perfectly correlated in training; at test the spurious cue is set to mislead. Goal-misgen severity = 1 − OOD accuracy (the model stays competent in-distribution but pursues the proxy goal off-distribution). We trained 48 models across 8 kinds of minima (optimizer / batch / learning rate / weight decay / SAM), 6 seeds each, and measured each minimum's sharpness (filter-normalized accuracy drop under weight perturbation).

Capability is held fixed: every model has train acc = in-dist acc = 1.000. So all OOD variation is genuine goal misgeneralization, not incompetence.

Result: the kind of minimum drives goal-misgen severity from 0.39 to 0.94 (~2×) with architecture, data, and in-distribution accuracy all identical.
  • Sharper minima goal-misgeneralize more — Pearson r = 0.40 (p = 5.2e-03), Spearman ρ = 0.35. Consistent with "flat minima help OOD," but a modest correlation: sharpness is real but not the whole story.
  • The dominant lever is the optimizer's feature-learning bias, not sharpness. Adam–small-batch misgeneralizes least (0.44 — per-parameter normalization gives the hard true cue a fair share vs the easy shortcut; same mechanism as Part 1's hedging). SGD high-LR is worst (0.86).
  • SAM, despite flattening, does NOT reduce misgen here (0.82–0.83) — matches the literature caveat that SAM fails under strong spurious correlation.

What this says about your original question

You asked whether the loss-equivalent minima LLMs reach can be as different as consequentialism is from deontology, with one aligned and one not. In this controlled setting:

  • Yes, the worldviews can be genuinely different and still loss-equivalent — behavior on edge cases diverges completely while training/agreement loss is identical.
  • But "near in loss" is the wrong axis. The frameworks are not just near — they are in the same basin, connected by a flat-loss path. The difference is orthogonal to the loss landscape, invisible to barrier/connectivity geometry, and surfaces only off-distribution.
  • For alignment this is the uncomfortable version of your intuition: you cannot locate the misaligned worldview by inspecting the loss surface or by checking mode-connectivity; an aligned and a misaligned solution can be flat-path neighbors. Detection has to come from targeted off-distribution / mechanistic probes, not geometry.

Limitations (honest)

  • This is a 1-hidden-layer MLP on synthetic cues. The zero barrier is partly because the agreement distribution is solvable with partial use of either cue; deeper nets / harder tasks may show a residual barrier (Lubana finds it is setup-dependent). The toy is an existence proof that frameworks can be loss-connected, not a claim that they always are.
  • "Consequentialist vs deontological" here is operationalized as outcome-cue vs rule-cue, not full moral reasoning. Scaling to real moral dilemmas (datasets below) is the next step.
  • Part 1's "hedge" may itself be capacity-dependent; a bottleneck that cannot represent both cues could force commitment — worth testing.
